# Infer. — AI 리서치 동아리 런칭 필름 (30초)

`out/infer_launch_film.mp4` — 1440×1440, 60fps, 30.0초, 120 BPM / 60박, -14 LUFS

Apple 키노트 스타일의 2D 원테이크 모션그래픽입니다. 컷·크로스페이드·블러인이 하나도 없고, 모든 장면이 바로 앞 장면의 오브젝트가 모양을 바꿔서 만들어집니다. 커서가 클릭·드래그·롱프레스로 모든 변화를 이끕니다.

## 구성 (비트맵)

| 박 | 시간 | 장면 |
|---|---|---|
| b1–b16 | 0–8s | **Open** — `Infer.` 워드마크가 마침표 속으로 아코디언처럼 접힘 → 점이 검은 pill로 커지며 라벨이 마스크 위로 올라옴 → 클릭하면 조리개 6날이 닫혔다가 사진 위로 열림 → 원이 사각형이 되고, 3×3 그리드가 종이지도처럼 펼쳐짐(가운데 → 십자 → 모서리) → 벤토로 재배치 → 채팅·loss 곡선 타일이 밀려 들어오고 태그 칩이 튀어나옴 → 클릭해서 줌 |
| b17 | 8.0s | **드롭** — 줌이 정확히 드롭에 맞춰 끝남 |
| b17–b26 | 8–13s | **Glass** — 유리 글자 `Relight`가 한 글자씩 튀어나옴 → 녹아서 물방울이 됨 → 유리 툴바 → 조정 아이콘이 슬라이더로 바뀜 → 드래그하면 낮 사진이 골든아워로 다시 밝혀짐(정렬된 두 장의 실사) → 노브가 유리 렌즈가 됨 → 유리 구슬 → 다음 사진이 구슬 안에서 열림 → 잠금화면(유리 시계, 유리 뮤직 플레이어) |
| b27–b42 | 13–21s | **Stage** — 잠금화면이 폰으로 물러나며 베젤이 자라남 → 다이내믹 아일랜드가 액체처럼 늘어나 끊어져 날아가 Mac 창이 되고 블라인드처럼 말려 올라감 → 배경화면을 길게 눌러 Safari 탭으로 드래그 → 동아리 랜딩 페이지의 히어로가 됨 → 스크롤하며 LLM Agent / Diffusion / Voice 프로젝트 카드 → 히어로가 데모데이 포스터 액자로 바뀜 → 프레임 색과 사이즈 선택 → 버튼이 날아와 "Order print"가 됨 |
| b43–b48 | 21–24s | **Order** — 검은 도형 하나가 Ordered ✓ → Printing % → On its way(경로를 달리는 밴) → Delivered ✓ 로 계속 모양을 바꿈 |
| b49–b56 | 24–28s | **Wall (브레이크다운)** — 원이 화면을 덮고 1박 동안 검은 화면 → 식물 그림자가 지는 벽에 걸린 액자로 수축 → 같은 조리개가 포스터 위로 열렸다 닫힘 → 액자가 화면을 덮고 pill → 점으로 |
| b57–b60 | 28–30s | **Return** — 비트 복귀에 맞춰 글자들이 점에서 스프링으로 튀어나옴. 마지막 프레임 = 첫 프레임 (루프 가능) |

## 기술 구성

- `index.html` 하나가 영상 전체입니다. 모든 프레임은 `await seek(t)`의 순수 함수입니다. CSS 트랜지션, 타이머, 프레임 사이에 이어지는 상태가 없습니다.
- 스프링: 닫힌 형식의 스텝 응답. 목표값이 여러 개인 값은 변경마다 스프링 하나씩 더한 합 `S(t, keys)`입니다.
- Liquid glass: WebGL2 합성기로 구현했습니다. 유리 아래 장면의 복제본을 둥근 사각형이나 글리프 거리장으로 굴절시키고, R/G/B를 서로 다른 배율로 세 번 샘플링해 색수차를 만들고, 림 라이트를 더합니다. 유리 글자는 캔버스로 그린 글리프에서 EDT 거리장 아틀라스를 만들어 씁니다.
- Goo: 같은 그룹의 프리미티브를 smooth-min으로 합칩니다. 물방울, 다이내믹 아일랜드, 슬라이더-렌즈가 여기에 해당합니다.
- 조리개: 육각 개구부 주위의 6날. 각 날은 두 꼭짓점, 두 변의 연장선, 그 사이의 짧은 호로 이루어집니다.
- 워드마크 압축: Archivo의 wdth 축(62–125)을 정적 인스턴스 64개로 만들어 연속적으로 좁히고, 나머지는 scaleX로 처리해 글자가 계속 붙어 있게 합니다.
- 푸티지: 전 프레임 키프레임(VP9 `-g 1`) WebM을 blob URL로 불러오고, 매 프레임마다 `seeked`를 기다립니다.
- 렌더: Playwright로 240 서브프레임/초를 캡처하고, ffmpeg `tmix`로 4:1 블렌딩해 60fps로 만듭니다(`tools/render.mjs`).
- QA: 박마다 프레임 1장씩 확인하고, 프레임 차이가 이웃의 3배를 넘는 단일 프레임 튐을 검사합니다(`tools/qa.py`).

## 사운드

- 음악: Mixkit "Talent in the Air" (121.72 BPM으로 측정 → rubberband로 정확히 120 BPM으로 늘림). 마디 단위로 편집했습니다.
  - 브레이크다운 끝 + 라이저 → 인트로
  - 드롭 → b17
  - 드롭아웃(조용한 구간) → 벽 장면
  - 드롭 재등장 → 워드마크 복귀
  - 킥 온셋이 영상 박자 그리드와 약 5ms 안에 맞습니다.
- 효과음: Mixkit에서 받은 효과음 37종을 65개 이벤트에 배치했습니다. 합성음은 없고, 각 효과음은 측정한 피크가 이벤트 시각에 오도록 놓았습니다(`tools/build_audio.py`).
- 최종 믹스: 2-pass loudnorm으로 -14 LUFS, 트루 피크 -1 dBFS.

## 다시 만들기

```bash
cd film
python3 -m http.server 8765 --bind 127.0.0.1 &      # 정적 서버
node tools/stills.mjs /tmp/stills 3.0 8.3 15.5 25.7  # 스틸 확인
node tools/render.mjs /tmp/render 3 60 4             # 영상 렌더 (워커 3개, 60fps, 서브프레임 4)
ffmpeg -f concat -safe 0 -i /tmp/render/chunk_list.txt -i audio/film_audio.wav \
  -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest out/infer_launch_film.mp4
```

브라우저에서 `index.html?play`를 열면 실시간 미리보기(음악 포함)로 재생됩니다.
